# Sistema MVP - Gestão de Estoque Solidário (Associação Terra Viva)

Sistema desenvolvido como MVP (Minimum Viable Product) para otimizar o fluxo de doações, controlo de stock e combate ao desperdício alimentar na Associação Terra Viva (Alinhado com a ODS 2).

## 🛠️ Tecnologias Utilizadas
* **Python (Flask):** Framework web para o desenvolvimento do backend e rotas.
* **SQLite:** Base de dados leve integrada para persistência local.
* **Bootstrap:** Framework CSS utilizada para estilização responsiva da interface.

## 📁 Estrutura do Projeto
- `app.py`: Ficheiro principal com a lógica do servidor e rotas do Flask.
- `database.db`: Base de dados SQLite com as tabelas do sistema.
- `templates/`: Pasta com os ficheiros HTML (`index.html`, `cadastrar.html`, `painel.html`).

## 🚀 Como Executar o Projeto Localmente

1. Certifica-te de que tens o Python instalado no teu computador.
2. Instala o Flask (se ainda não o tiveres):
   ```bash
   pip install flask
1. Clona este repositório ou descarrega os ficheiros para uma pasta local.
2. Abre o terminal na pasta do projeto e executa a aplicação:

   ```bash
   python app.py
3.  Acede no navegador através do endereço: http://127.0.0.1:5000
